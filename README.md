# homepage

Source of [mistwu.com](https://mistwu.com), built with [Astro](https://astro.build) on top of the [AstroPaper](https://github.com/satnaing/astro-paper) theme.

## Development

```bash
pnpm install
pnpm dev
```

## Writing

Add Markdown/MDX files under `src/content/posts/`.

## Deploy

```bash
pnpm run deploy
```

Builds the site and deploys it to Cloudflare Workers (static assets), served at mistwu.com.
